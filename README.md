# 🎯 Guess The Number (Угадай число)

Мини-игра на Python, в которой компьютер загадывает случайное число, а ваша задача - угадать его за минимальное количество попыток. В игре есть система подсчета статистики и сохранение результатов в JSON.

## 🛠 Стек
- Python 3.x
- JSON (для хранения статистики)

## 🔗 Установка

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/pieceandwork/Guess_The_Number.git
   cd Guess_The_Number
   ```
2. Запусти игру:
    ```bash
   python Game_Ru.py
   ```
## 📂 Структура проекта
📦 Guess_The_Number

┣ 📜 Game_Ru.py    # Основной скрипт игры

 ┣ 📜 stats.json    # Файл с сохраненной статистикой (создается автоматически)

 ┣ 📂 .venv/        # Виртуальное окружение (не загружается на GitHub)
